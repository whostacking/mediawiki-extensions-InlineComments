# Codex icons

These SVG files are unmodified copies of the Wikimedia Codex icon set, imported
from Wikimedia Commons (gallery: <https://commons.wikimedia.org/wiki/Wikimedia_Codex_icons>).

| File | Commons source |
| --- | --- |
| `cdxIconEdit.svg` | [File:Codex icon edit.svg](https://commons.wikimedia.org/wiki/File:Codex_icon_edit.svg) |
| `cdxIconTrash.svg` | [File:Codex icon trash.svg](https://commons.wikimedia.org/wiki/File:Codex_icon_trash.svg) |
| `cdxIconLink.svg` | [File:Codex icon link.svg](https://commons.wikimedia.org/wiki/File:Codex_icon_link.svg) |

The icons are licensed under
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Codex is the design system for Wikimedia: <https://doc.wikimedia.org/codex/latest/>.

The SVGs are painted as CSS masks (see `resources/sidenotes.css`), so their
`fill` color is ignored and each icon inherits the theme color of its button.
